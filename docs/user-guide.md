# 使用说明

本文面向在本机运行项目的学生、教师和演示人员。安装与配置见项目根目录的 [README](../README.md)。

## 一、准备课程资料

1. 将有权使用的 PPTX、DOCX、PDF 课程资料放在 `COURSE_MATERIALS_DIR` 指向的目录。系统不会从 GitHub 下载学校课程原件。
2. 复制 `.env.example` 为 `.env`，填写资料路径、`TEACHER_ACCESS_CODE`、`MEDIA_SIGNING_KEY`，需要 AI 功能时填写 `QWEN_API_KEY`。
3. 运行 `scripts/import_course_materials.py` 导入 PPT 和 Word。任务列表从两份指定指导手册提取；报告模板从匹配的 Word 文档读取。如果原件缺失，相关任务或模板不会出现。
4. Windows 上安装 PowerPoint 后，可运行 `scripts/import_visuals.py` 建立完整页面图像索引。它保留幻灯片中的原生图形，适合接线图、流程图等视觉问题。
5. 打开首页，确认资料统计和模型状态。资料导入后可以在教师工作台继续上传补充 PDF/DOCX。

导入脚本使用实际资料内容生成索引。重新导入时请先备份数据库和 `uploads/`；不要将原始资料、数据库、索引或学生数据加入版本控制。

## 二、学生操作

### 登记与课程问答

首次进入“我的信息”填写姓名、学号和班级。学生标识保存在当前浏览器；更换浏览器或清理浏览器数据后需要重新登记。课程问答可选择模块、输入问题，必要时上传现场图片。回答会显示资料依据，课件图片通过弹窗查看。

### 代码分析

选择或让系统识别代码语言，粘贴源代码后提交分析。Python 会先做本地语法检查；AI 可对常见语言作静态阅读。系统不会执行提交的代码，因此运行结果仍需自行验证或补充截图。

### 任务验收与实验报告

1. 进入“任务验收”，选择模块和任务，阅读任务要求、配图和评分点。
2. 如果任务提供“下载报告模板”，先下载对应的 DOCX。该文件来自教师导入的原始报告模板。
3. 在“作品与代码”填写功能说明、关键代码或运行证据，也可添加源码、项目 ZIP、截图等附件。
4. 在“实验报告”填写报告内容或上传 DOCX/PDF。作品与报告两部分均需要提供内容或附件。
5. 点击“提交并评分”。评分需要调用已配置的模型，图片和文件解析可能耗时。完成后任务顶部显示总分和两部分分数，点击“查看评分明细”阅读逐项反馈。
6. “提交记录”可重新打开历史结果、修订或重新提交。修订会生成新的提交记录，旧版会留给教师查看。教师复核意见与最终分数也显示在学生端。

AI 初评按作品与功能 70%、实验报告 30% 合成。模型只能根据提供的代码、文字和证据判断；需要现场运行或硬件验证的内容仍应由教师核对。

### 学习回顾

“学习回顾”汇总当前学生的提问、代码分析、模块活动和任务结果，供学习过程参考，不直接替代课程最终成绩。

## 三、教师操作

打开“教师工作台”并输入 `.env` 中的 `TEACHER_ACCESS_CODE`。访问码适用于本机演示，不代表正式教师账号。

### 作业管理

- 固定的“作业管理”入口显示全部已导入任务、提交人数、提交次数及待复核数量。
- 点击任务可查看要求和评分标准。编辑后会保存为新版本；旧版仍在版本记录中，已提交的评分依据不会被新内容覆盖。
- 提交列表支持任务、班级、姓名/学号、日期和复核状态筛选。即使没有学生提交，也会显示任务与空状态。
- 点开单条提交可阅读作品文字、报告文字、附件、AI 评分明细和复核历史。可分别下载作品 ZIP、报告 ZIP，或整次提交 ZIP。
- 教师可以填写复核意见、状态和最终分数。确认通过时可设置最终分数；每次保存都会增加一条复核记录。
- 选中提交后可点击“删除所选提交”。该提交会从学生和教师页面移除；数据库和附件保留，以便追溯。删除前有确认提示。

### 学情分析、资料与审核

“学情分析”按班级、模块和日期展示活动统计；“最近任务提交”只提供进入作业管理的快捷入口。资料管理可以上传补充文档和建立页面图像索引。回答审核用于复核课程问答，和作业复核是两套独立记录。

## 四、常见情况

| 现象 | 检查方式 |
| --- | --- |
| 没有任务或报告模板 | 检查指导手册和报告模板是否在原始资料目录，重新运行导入脚本，并查看导入日志 |
| AI 评分失败 | 检查 `QWEN_API_KEY`、模型服务网络和后端日志；失败时不会产生成功评分记录 |
| 评分完成却没看到明细 | 任务顶部先看分数摘要，再点“查看评分明细”；历史评分也可从“提交记录”打开 |
| PPT 图像不显示 | 检查是否在 Windows 安装 PowerPoint 并执行图像索引脚本 |
| 教师端无法进入 | 检查 `.env` 中的访问码，重启后端以加载新的配置 |
| 更换浏览器后看不到旧记录 | 学生标识存于旧浏览器；当前项目没有正式账号迁移或找回功能 |

## 五、备份

需要保留完整演示数据时，关闭后端，再同时备份 SQLite 数据库、`uploads/`、`knowledge_base/processed/`、`knowledge_base/indexes/` 和课程原件。只备份数据库无法恢复附件和部分图像。备份文件可能包含学生个人信息，应按所在单位要求保管。
