# 毕业设计实验验证报告（重新运行）

## 实验范围

本轮在清除旧的本机测试记录后，从课程资料重新冻结案例并完整运行。案例仍是预先固定的 30 道文本题（知识 8、操作 12、复合 10）、6 道图片题和 6 道代码题，覆盖四个课程模块；使用相同的 `QWEN_MODEL`。课程资料为 44 份 PPT、88 份 DOCX 和 628 页 PPT 图像索引。资料与案例未变，快照 SHA-256 仍为 `a6332da8d25ed6e9c0500a6e51fb3fe86350bc96fa091f533020735ee1b5011e`。**这是新生成的模型回答，不是新的题库或独立样本。**

文本题运行单 Agent＋RAG（冻结的 Top 5 片段）和单 Agent 无 RAG；10 道复合题另由课程问答、实验指导和整合三个步骤处理。图片、代码题各运行一次。102 个模型请求全部成功，未发生中断续跑或错误重试。本轮运行器已对生成文本应用当前的输出约束，但代码题 C03 仍经过模型分析；线上代码分析函数对此精确代码片段另有确定性处理，因此该题的模型结果**不能代表线上最终输出**。单 Agent 无 RAG 使用不同的通用提示，差异不能全部归因于检索。

检索 Recall@5 要求人工标注的同一文件、同一页进入 Top 5；来源文件命中率只要求文件相同。82 条最终回答按事先固定的关键点、事实错误、引用是否真正支持结论和不确定性表达规则逐条复核，复核理由保存在本机 `evaluation/private/review.csv`。复核仅由本项目研究者一人完成，未做盲审或第二人复标。程序计算的“引用编号有效”只检查编号在候选范围内，**不等于语义事实核验**。

## 本轮结果

同页检索 Recall@5 为 **24/30＝80.0%**；同文件命中率为 **26/30＝86.7%**。同页未命中案例是 T01、T05、T12、T13、T15、T16。由于资料和检索快照未变，这两项与旧报告一致。

单 Agent＋RAG 与双 Agent 的引用编号有效率均为 100%，但 RAG 只有 83.3% 的关键结论得到人工判定的来源支持。在**同一 10 道复合题**上，单 Agent＋RAG、无 RAG、双 Agent 的关键点覆盖分别为 100%、65%、100%；事实错误分别为 2/10、5/10、0/10。双 Agent 每题需要三次模型调用，平均耗时 23.61 秒；10 题零错误不能推断其在更大题集上稳定为零。

## 失败案例与解释

- T10 的 RAG 回答把 `_id` 列说成所有 Android 场景的官方强制主键名，适用范围被夸大。
- T25 的 RAG 回答沿袭课件错误，把 180–290 nm 称为红外波段；这个范围属于紫外波段。检索到课程资料不保证资料本身正确。
- T28 的 RAG 答案在表格中仍写“彻底消除”干扰，而后文已有较审慎的表述；当前输出约束未覆盖表格里的短语。
- T29 的无 RAG 答案错误声称 ADAM-4150 只有 DO 而没有 DI，偏离本课程接线案例。
- C03 的模型路由仍把删除后果说成不可逆；C06 把占位通道解释成 DO1。这说明针对固定措辞的输出替换仍不能代替代码语义检查。

## 结论与边界

本轮同一模型、固定案例的实测显示，RAG 和双 Agent 在课程关键点覆盖上优于无 RAG；双 Agent 在 10 道复合题上取得较低错误数，同时增加调用量和延迟。与旧报告的数值变化属于**同模型重复采样差异和系统修改共同作用**，没有隔离随机性，不能全归因于本次整改。案例由人工精选，样本少且只有一名复核者；图片和代码各 6 例不代表真实设备或代码执行效果。没有其他模型接口，因此开题报告所述跨模型比较仍未完成。

本机私有快照、账本与复核表可以按案例 ID 追溯每项汇总；公开仓库只包含脚本、[匿名案例索引](../evaluation/cases-manifest.json)和[汇总结果](../evaluation/results/summary.json)。课程原文、逐条回答及个人信息不公开。
