# 课程助教界面设计语言：Academic Atelier

## 目标

让界面像一张清晰的课程工作台：安静、可信、可长时间阅读。用克制的材料感表达“教学与实训”，避免装饰抢过课件、代码和反馈。

## 视觉基调

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 墨绿 `#1b2b27` | 主文字 | 标题、主要内容 |
| 松绿 `#176553` | 主操作 | 按钮、选中状态、链接 |
| 暖纸 `#f7f6f1` | 页面底色 | 降低长时间阅读的眩光 |
| 米白 `#fffefa` | 内容表面 | 对话、任务、卡片 |
| 黄铜 `#ad8050` | 少量强调 | 栏目标记、细线、选中边线 |
| 灰绿 `#687770` | 次要文字 | 说明、时间、元信息 |

深色侧栏稳定导航，内容区保持浅色。黄铜只用于定位视觉焦点，不用于大面积填充。

## 排版与组件

- 大标题用系统可用的宋体字族，正文用无衬线字族；大标题 27–42 px，正文 13–14 px，辅助文字不低于 11 px。
- 内容卡片用细边框、轻阴影和 8–18 px 圆角。通过留白建立层级，避免叠加多层渐变。
- 主按钮用松绿实底；选中导航使用浅色表面加黄铜左边线；状态采用文字与色彩共同表达。
- 对话阅读宽度控制在约 880 px。证据卡片、代码和实验报告保持可扫描的行距。
- 任务页在中等宽度改为上下布局，任务列表以两列短卡展示，详情占整行。

## 页面层级

1. **课程问答**：问题输入始终可见；欢迎区用一句明确主张和四个示例问题引导开始。
2. **任务验收**：先选任务，再看要求与评分点，最后提交作品；评分卡中清楚分开 AI 初评与教师意见。
3. **代码分析**：代码编辑区与追问区分开；分析结果以对话形式阅读，语法问题突出显示。
4. **学习回顾与教师工作台**：指标卡只负责快速概览，详细解释留给列表和正文，避免数字淹没决策信息。

## 实施位置

样式集中在 `frontend/src/atelier.css`，由 `frontend/src/main.js` 最后加载，以便在不改变业务组件的情况下统一视觉语言。
